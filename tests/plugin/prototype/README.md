# P0 synthetic device diagnostic

This is investigatory tooling, not the sync plugin. Review source and package before asking the owner for permission to copy anything to the Kindle. No device copy is authorized by this document.

## Build and inspect on the PC

From this directory run python -B generate.py, then python -B verify.py. Generated files are ignored by Git. generated/hackindle-p0-package.zip contains only the two synthetic fixtures and three plugin Lua files. The generator uses only Python standard library; no book or personal text is read. EPUB content consists of synthetic numbered segments. PDF has three original pages and two labelled columns. MOBI remains pending; no converter was run.

The diagnostic accepts only the exact hackindle-p0-fixtures/hackindle-p0.epub and .pdf paths and the generated bytes' size and Adler-32 fingerprints. This guards accidental use, not malicious collisions. It reads the open fixture only, performs no network calls, and appends observations to settings/hackindle-p0-results.txt under KOReader settings. It does not force statistics flush, change page, or access annotation records. Normal KOReader opening/reading of synthetic books can still create its own metadata and statistics. Close any active selection before invoking the probe; selection preservation itself requires separate validation and is not claimed.

## After review and explicit copy permission only

1. Exit KOReader cleanly. Copy hackindle-p0.koplugin into KOReader's plugins/ and hackindle-p0-fixtures to a separate device location, preserving directory names. Start KOReader and open only the generated EPUB. Open the menu, More tools, Hackindle P0: capture synthetic observation. Each action appends one record. Record action and time externally to associate records with steps. Stop on an error; report the exact message without sharing other device files.
2. Capture EPUB at segment 001. Turn a page, wait over the native minimum, capture again. Return to the same displayed passage and capture; change font size, return to the same segment and capture. Record visible segment identifiers, font sizes, positions and screen state at each step. Extracted byte length is not a character count or proof of exact visible boundaries. Repeat on a new day; do not infer deduplication from this tool.
3. Jump from an early segment to a much later one and record the two visible segment ranges; do not assume intermediate segments were read. Observe whether position and displayed text remain unchanged after each capture. To test selection restoration, select a synthetic word and check that the diagnostic refuses to extract while selection is active if accessible. If menu invocation closes the selection, report the test inconclusive; do not claim restoration.
4. For native statistics, capture on a synthetic page, wait at least 10 seconds, turn a page, capture, then use KOReader's normal statistics display/flush actions as available and capture twice without turning the page. Record actual min/max settings and timestamps shown by the device, then repeat across suspend/resume, book close/reopen and reporting-zone midnight. native_stats=unavailable means the plugin instance is not exposed at the guessed location; it is not evidence of zero time. Do not change or clear the native statistics database. Reconciliation and non-overlap must be evaluated separately; this diagnostic does not implement them.
5. Open the synthetic PDF, capture page 2, then repeat with zoom/crop, rotation, scroll and reflow, including a partially visible word and a column boundary. Compare physical page 1/2/3 box records and mapped corners to visible text. Note geometry, viewport, display mode and visible labels at each action. Missing methods, non-rectangular viewports, clipping, differing coordinate systems or unusual box structures are inconclusive, not full-page credit. A more complete mapping probe may be needed.
6. Explicitly check first/last pages, empty/missing neighbours, multi-page highlights, edit note versus range, synthetic context after restart, and end of book. This diagnostic does not perform those operations or prove absence of statistics/selection side effects. Record failures and gaps rather than guessing.

Exit KOReader and copy only settings/hackindle-p0-results.txt for review, after checking it contains only synthetic fixture observations. It contains local Unix timestamps and may disclose test times. Do not share other settings, databases, logs or book files. To uninstall, delete only the diagnostic plugin directory, the two synthetic fixtures and its result file, plus fixture-specific sidecars the owner identifies. Do not remove unrelated statistics or settings.


## Invariant diagnostic update

The EPUB and PDF fixture bytes are unchanged. After source and package review, the owner exits KOReader and manually replaces only the existing hackindle-p0.koplugin folder with the package's folder; the owner does not need to recopy the books. Reopen the same synthetic EPUB and run the opt-in menu action with no selection active. Record the invariant results. Change the font size, run the action again on the same synthetic EPUB, and compare fixed_span_start/end and invariant_cre_range_union, invariant_utf8_scalars_v1, invariant_paragraph_delimiter and invariant_final_position_unchanged. A failure or unavailable result is evidence to report, not a pass. The expected fixed span is the first 30 Unicode scalar values of segment 001; the paragraph check explicitly expects a single newline between the end of paragraph 1 and start of paragraph 2. If CRE extraction uses different boundary rules this check reports a failure; do not change its expectation to match the device without investigation.

The range probe uses actual synthetic XPointers and checks overlap, repeat and a distant disjoint range. Counter rule v1 counts Unicode scalar values including spaces and combining marks, with no Unicode normalization, and rejects malformed UTF-8. It does not establish the correct accounting rule for all EPUB text. The diagnostic checks reported position after extraction; it still does not test selection restoration.

Only after EPUB captures, optionally run a PDF capture and zoom/crop capture on the same original physical page. Record visible_page entries and the four named inside-corner results for each page; compare same-page results and mode flags, not captures of different pages. The probe does not calculate visible-text intersection. Native tuple snapshots contain timestamps; only tuples from the matching synthetic document are reported after a document and native-digest check. They are raw native estimates, not proven exact attention intervals. Check the result before sharing and omit personal timestamps from public reports.
